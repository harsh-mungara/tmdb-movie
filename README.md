# TMDB-Movie-Sanius

# Project setup
- ### Clone the repo  
        https://github.com/harsh-mungara/tmdb-movie
- ### install modules
        npm install
- ### Run on android : npm run android
- ### Before run on ios fire below command
        cd ./ios && pod install &&  cd ..

- ### Project Modules & Flow:
     small cross-platform React Native app that showcase below functionality.
        - Fetch movies from TMDB Api's based on category with search functionality
        - Movie detail screen
        - Search screen
        - Favorite screen!
